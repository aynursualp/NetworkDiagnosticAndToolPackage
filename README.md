Network Diagnostic and Tool Package

This project is a Python-based diagnostic tool package that includes basic network diagnostic utilities and client-server communication mechanisms using socket programming.

🚀 Features (Modules)

1. Machine Information: Retrieves and displays the device's hostname and IP address.

2. Echo Test (Client/Server): Establishes a ping-pong connection over TCP to verify data transmission and matching.

3. SNTP Time Synchronization: Fetches the global network time from pool.ntp.org using the NTP protocol.

4. Socket Settings & Error Management: Modifies socket buffer sizes, switches between blocking and non-blocking modes, sets timeouts, and intentionally catches connection errors.

5. Simple Chat: Enables two-way messaging between a client and a server. All messages are logged into chat_file.txt with an SNTP timestamp.

6. Web Dashboard: A Flask-based interactive web interface to monitor system information, SNTP time, and chat logs in real-time.

🛠️ Prerequisites & Installation

This project uses standard Python libraries (such as socket, sys, and os) along with a few external ones. To install the required external libraries, run the following command in your terminal:

pip install ntplib flask

💻 How to Run

1. Main CLI Application (Core Project)

To test the network modules, launch the interactive main menu from your terminal in the project directory:

python main.py

Note: To test the Echo and Chat modules properly, you need to open two separate terminal windows (run the Server on one terminal, and the Client on the other).

2. Web Dashboard (Reporting Interface)

To view the system data and chat logs in a user-friendly browser interface, run the Flask backend:

python app.py

After running the command, open your web browser and navigate to: http://127.0.0.1:5000

📝 Notes for Testing

The chat logs are saved in chat_file.txt. When running the client and server on the same local machine (localhost), duplicate log entries might appear due to both the server and client writing to the same local file simultaneously. This is expected behavior for local testing.

The **pycache** folders and .cpython files are automatically generated by Python and are excluded from the repository.
